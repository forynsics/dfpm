A plain-language field guide

New to digital forensics?

Start with the evidence you have. dfpm connects common evidence sources to the tools that can work with them.

01

Disk & files

Recover deleted files, inspect file systems, and identify unusual content without changing the original evidence.

02

Memory

Inspect a memory capture for processes, network connections, injected code, and other traces of system activity.

03

Windows activity

Read event logs, Registry files, shortcuts, and other artifacts that describe what happened on a Windows machine.

04

Web activity

Extract browsing history, downloads, cookies, and cached data from common browsers.

What about system-wide installers?

Some tools require Windows installers or shared runtimes. dfpm clearly warns you before one writes outside these folders, explains what will change, and asks for permission. Regular tool updates never silently update shared system software.
